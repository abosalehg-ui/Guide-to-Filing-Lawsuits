## ✨ المميزات

| الميزة | الوصف |
|--------|-------|
| 📱 **تصميم متجاوب** | يعمل بسلاسة على جميع الأجهزة (هواتف، أجهزة لوحية، حواسيب) |
| 🔍 **بحث فوري** | بحث في جميع البنود — الدعاوى والإنهاءات والخدمات الإلكترونية، ويُحفظ الاستعلام في الرابط |
| 🔤 **بحث عربي متسامح** | يطابق الكتابة بدون همزات أو تشكيل: `احوال` تعطي نفس نتائج `أحوال` |
| 🎯 **تصنيف منظم** | تصنيف واضح ومنطقي لجميع أنواع الدعاوى |
| 🔗 **روابط مباشرة** | كل تصنيف له رابط قابل للمشاركة، وزر الرجوع في المتصفح يعمل |
| ⌨️ **تنقّل بلوحة المفاتيح** | كل العناصر قابلة للتشغيل بلوحة المفاتيح، والتركيز ينتقل مع المحتوى عند التنقّل |
| 🏛️ **المحكمة المختصة** | تظهر لعدد من الدعاوى الشائعة مع رابط المصدر الرسمي |
| 🖨️ **طباعة كاملة** | الطباعة تُخرج كل البنود، لا القسم المفتوح فقط |
| 🌙 **واجهة عربية** | دعم كامل للغة العربية واتجاه RTL |
| ⚡ **أداء سريع** | ملف واحد بلا أي مكتبات أو خطوة بناء |

## ✍️ تعديل المحتوى

كل المحتوى في `data.js` وحده، ولا يتكرر في `index.html`: البطاقات والأعداد وفهرس
البحث كلها تُبنى منه عند التحميل.

- **إضافة دعوى أو خدمة:** أضف اسمها إلى المصفوفة المناسبة.
- **إضافة تصنيف أو مجموعة:** أضف كائناً فيه `title` و `icon` و `color` و `summary`
  (والألوان المتاحة: `blue`, `green`, `orange`, `purple`, `red`, `teal`).
- **تفاصيل دعوى بعينها:** أضفها في `caseDetails` باسم الدعوى نفسه، مع مصدر رسمي في
  `sources` إلزامياً. لا تُضاف معلومة بلا مصدر.

بعد أي تعديل شغّل `npm test`: إن كان في `data.js` فاصلة أو علامة تنصيص ناقصة، يفشل
أول اختبار ويذكر موضع الخطأ.

## ⌨️ الاختصارات والروابط المباشرة

| الاختصار | الوظيفة |
|---|---|
| `/` | الانتقال إلى البحث وتركيز حقل الإدخال (يعمل أيضاً على لوحة المفاتيح العربية: زر «ظ») |
| `Esc` | إغلاق النافذة المنبثقة |
| `Tab` / `Enter` | التنقّل بين العناصر وتشغيلها |

حالة التطبيق محفوظة في عنوان الصفحة، فيمكن مشاركة رابط مباشر لأي قسم أو تصنيف:

```
index.html#/services              الخدمات الإلكترونية
index.html#/lawsuits/labor        الدعاوى العمالية
index.html#/steps                 خطوات التقديم
index.html#/search/وكالة          نتائج البحث عن «وكالة»
```

## 🧪 الاختبارات

**اختبارات البيانات والترميز** تعتمد على وحدات Node المدمجة فقط، فلا حاجة لتثبيت شيء:

```bash
npm test          # أو: node --test tests/*.mjs
```

تشغّل `data.js` والجزء الخالص من `app.js` نفسه في بيئة معزولة، وتتحقق من: سلامة
البيانات وعدم تكرارها، أن فهرس البحث الفعلي يحوي كل البنود، التطبيع العربي، أن كل
تفصيل دعوى له مصدر رسمي، تباين الألوان، وغياب السكربت المضمَّن و `innerHTML`.

**اختبارات المتصفح** تفتح الصفحة في Chromium وتجرّب السلوك الفعلي: الروابط المباشرة
والمشوّهة، انتقال التركيز، النافذة المنبثقة وزر الرجوع، البحث وحدّه الأعلى، اختصار
لوحة المفاتيح العربية، والطباعة:

```bash
npm ci
npx playwright install chromium
npm run test:e2e
```

Playwright اعتماد للاختبارات فقط؛ التطبيق نفسه بلا أي اعتماديات. النوعان يعملان
تلقائياً على كل دفعة عبر GitHub Actions.
